# Terrane

**Status:** Active | **Visibility:** Public | **Category:** Products

## Overview

**Terrane** — Custom 3D-printed relief maps. Main product repository with core functionality and architecture.

## Features

- 3D relief map generation
- Custom topography rendering
- Print-ready output formats
- Interactive preview
- Customization options

## Getting Started

```bash
git clone https://github.com/High-Shot/Terrane.git
cd Terrane
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npm run deploy
```
